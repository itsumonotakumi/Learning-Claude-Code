Claude Code の「中身」を理解する

AIコーディングエージェントは魔法ではありません。たった一つのシンプルなループと、その上に積み重なる層(レイヤー)でできています。この教材は、その仕組みを専門用語をかみ砕いて、なぜ学ぶと得なのかと一緒に、日本語で解説します。

📖 この教材の使い方
左のメニューから気になるテーマへジャンプできます。各テーマのカードをクリックすると、「なぜ学ぶ?(メリット)→ 概念 → 仕組み → たとえ → 実物との対応 → 要点」の順で開きます。上から順に読むのがおすすめですが、どこからでも読めます。

💡そもそも、なぜ仕組みを学ぶの?

「使えればいいじゃないか」と思うかもしれません。でも仕組みを知ると、Claude Code(や同種のAIツール)の使いこなし方が一段変わります。理由は4つあります。

🎯 結論：AI = 「賢いモデル」＋「それを動かす道具立て(ハーネス)」
知能はモデル(Claude本体)の訓練から生まれます。一方で、ファイルを読む・コマンドを実行する・記憶する・権限を確認する——こうした「手足」や「環境」を用意しているのは、モデルの外側のプログラム(ハーネス)です。この教材で学ぶ19テーマは、すべてこのハーネスの部品です。
メリット1 ｜ 使いこなせる

権限・メモリ(CLAUDE.md)・サブエージェント・スキルなどの設定が「何のためにあるか」が分かると、狙った動きをさせられるようになります。手探りの設定から卒業できます。

メリット2 ｜ つまずきを理解できる

「急に前の話を忘れた」「同じ確認を何度もしてくる」「ループしている」——こうした挙動の原因が分かり、対処できます。コンテキスト圧縮やエラー回復を知っていれば納得です。

メリット3 ｜ 自分でも作れる

ここで学ぶパターン(ループ・ツール・MCP・マルチエージェント)はあらゆるAIエージェントに共通です。自分の業務自動化や独自エージェントを作る土台になります。

メリット4 ｜ AIの強みと限界が見える

「モデルがやっていること」と「外側の仕組みがやっていること」を切り分けられると、AIに何を任せ、何を任せないかの判断力が上がります。過信も過小評価もしなくなります。

🧠全体のメンタルモデル

最初にこの2枚の図を頭に入れておくと、19テーマが「バラバラの知識」ではなく「一つの絵の部品」として繋がります。

① 核：エージェントループ(これが全ての土台)

Claude Code の心臓部は、驚くほど単純な繰り返し(ループ)です。

①→②→③→①… を、モデルが「もう道具はいらない(完了)」と言うまで繰り返すだけ。これがエージェントの正体です。

② 構造：ループの上に積み重なる5つの層

このループだけでは不器用です。そこで「ループ本体は変えず」、まわりに機能の層を足していきます。この教材の5カテゴリは、そのまま5つの層に対応します。

🤝5. マルチエージェント基盤複数のAIが分担・協力・自律的に働くs12,15–19
⏱️4. 並行処理裏で動かす・定期的に動かすs13,14
🧩3. メモリ管理長い会話を圧縮し、大事なことを覚えるs08,09
🗺️2. 計画と調整計画を立て、役割を分け、失敗から立て直すs05–07,10,11
⚙️1. ツールと実行ループ・道具・権限・フック(核となる土台)s01–04
✅ 覚えておきたい一文
「ループは変わらない。変わるのはツール・知識・権限だ。」 どんなに高機能になっても、土台は最初の単純なループのまま。新機能は層として外側に足されるだけ——この視点があると全体が驚くほどスッキリ見えます。
